RIEPILOGO COMMESSE — ISTRUZIONI D'USO
=====================================

Cosa c'è in questa cartella
---------------------------
  Commesse.html                  L'applicazione (un unico file, non serve installare nulla)
  database_commesse.json         Database DIMOSTRATIVO con dati inventati (per provare)
  database_vuoto.json            Database vuoto, per iniziare da zero con le tue commesse
  demo\                          Copia del database dimostrativo (la stessa cosa)
  LEGGIMI.txt                    Questo file
  README.md                      Descrizione tecnica del progetto
  LICENSE                        Licenza MIT


REQUISITI
---------
  Browser: Microsoft Edge o Google Chrome (aggiornati)
  NON funziona su Firefox o Safari: manca il supporto per il salvataggio diretto su file
  Non serve internet, non serve installare niente


COME INIZIARE — PRIMO AVVIO
---------------------------
  1. Apri Commesse.html con doppio clic (o tasto destro > Apri con > Chrome/Edge)

  2. L'app si apre GIA' POPOLATA con due commesse dimostrative:
       70777 - Cliente A, in ritardo
       70812 - Cliente B, in linea

     Non devi selezionare nessun file. Guarda, clicca, prova.

  3. Quando hai capito come funziona, premi "Svuota dati demo" (pulsante rosso
     in alto a destra nella barra dei comandi) per partire da zero.

  4. Per collegare il TUO database: "Collega Archivio Condiviso" -> scegli il file.


DUE MODI DI FUNZIONARE
----------------------
  A) FILE LOCALE (uso normale, sul tuo PC)
     I dati dimostrativi sono dentro l'HTML. Il tuo database vero si collega
     con il pulsante "Collega Archivio Condiviso": da quel momento puoi salvare.

  B) SUL SITO (solo per provare le modifiche)
     Se apri la pagina da un indirizzo http/https, l'app legge da sola il file
     demo/database_commesse.json della repository. Nessun collegamento da fare:
     apri e vedi. In questa modalita' NON si salva: e' sola lettura, apposta,
     perche' non c'e' nessun file tuo da scrivere.

     Indirizzo online:
     https://casapad1968-hub.github.io/riepilogo-commesse/Commesse.html

     Per aggiornare i dati mostrati online basta modificare il file
     demo/database_commesse.json nella repository e ricaricare la pagina.


PERCHE' IL BROWSER NON SI COLLEGA DA SOLO A UN FILE TUO
-------------------------------------------------------
  Il browser non permette a una pagina web di aprire un file sul disco senza
  un tuo clic. E' una regola di sicurezza, non un limite dell'app.
  Per questo i dati dimostrativi sono dentro l'HTML, mentre il tuo database
  vero si collega con un clic - e solo cosi' il browser ti da' il permesso
  di SCRIVERE sul file, cioe' di salvare le modifiche.


ATTENZIONE — PRIMA DI USARLA CON I TUOI DATI
--------------------------------------------
  Quando l'app è collegata a un file JSON, ogni salvataggio SOVRASCRIVE quel file.
  Se provi con il database dimostrativo e poi salvi, i dati demo vengono modificati.
  Per questo conviene:
     - tenere il dimostrativo in una cartella a parte
     - usare database_vuoto.json (o una copia) per il lavoro vero


CARICARE LE TUE COMMESSE DA MS PROJECT
--------------------------------------
  Nella scheda "Nuova Commessa (Manuale / XML)":
     - Opzione A: carica il file XML esportato da MS Project
       L'app compila da sola numero commessa, descrizione, attività, date
     - Compila a mano solo i campi che l'XML non contiene:
       date dell'ordine, fabbricante, inizio fabbricazione

  Per AGGIORNARE una commessa esistente:
     - entra nel dettaglio della commessa
     - sezione "AGGIORNA FILE PROJECT XML DEL MESE"
     - carica il nuovo XML: le attività vengono sostituite, i dati inseriti a mano restano


DOVE STANNO I DATI
------------------
  Il database è il file JSON che hai selezionato all'avvio. Nient'altro.
  L'app non manda dati da nessuna parte: nessun server, nessun account, nessun cloud.

  Il browser tiene anche una copia temporanea interna (localStorage), usata per
  riaprire l'app con i dati già caricati.


CONSIGLI PER LA SICUREZZA DEI DATI
----------------------------------
  1. FAI UNA COPIA DEL JSON OGNI TANTO. Non c'è backup automatico.
     Suggerimento: una volta a settimana copia database_commesse.json in una
     cartella "backup" con la data nel nome (es. database_commesse_2026-11-16.json)

  2. NON mettere il file su un cloud pubblico (Drive/Dropbox condivisi)
     Se lo metti su un disco di rete condiviso, va bene: è il caso d'uso previsto

  3. GESTIONE ARCHIVIO PDF DEI CERTIFICATI:
     I documenti PDF allegati alle commesse vengono archiviati nella cartella
     dedicata 'archivio_pdf/' (suddivisi automaticamente in sottocartelle per
     numero di commessa) e memorizzati nel motore IndexedDB del browser.
     In questo modo il file JSON e il salvataggio locale restano sempre
     leggerissimi (pochi KB), senza alcun limite di dimensione e senza rischi
     di saturazione.


PROTEZIONE CONCORRENZA MULTI-UTENTE
------------------------------------
  - Protezione attiva contro sovrascritture accidentali:
    1) Rilevamento automatico timestamp: se un collega salva modifiche sul disco
       mentre hai l'app aperta, l'applicazione lo rileva istantaneamente.
       Al momento del tuo salvataggio ti avvisa con un chiaro messaggio di conflitto,
       mostrando data e ora della modifica del collega e permettendoti di scegliere
       se sovrascrivere o ricaricare i dati freschi da disco senza sovrascrivere alla cieca.
    2) File di lock condiviso (database_commesse.lock): registra l'operatore attivo
       e l'orario di apertura nella cartella condivisa.
    3) Rilascio automatico del lock alla chiusura della finestra o scheda del browser.
    4) Badge Operatore in testata: permette di impostare la propria sigla/nome
       (es. 👤 Gaetano) con un semplice clic.

LIMITI DA CONOSCERE
-------------------
  - Nessuna password: chi apre il file vede tutto. Va bene per uso locale/aziendale protetto.
  - Nessun backup automatico (vedi consigli sopra).


COMANDI PRINCIPALI DELL'APP
---------------------------
  💾 Salva Dati Condivisi      Scrive sul file JSON collegato
  🔗 Collega Archivio Condiviso  Cambia il file JSON (o lo ricollega dopo un riavvio)
  📂 Carica JSON Manuale       Importa un JSON senza collegarlo in scrittura
  📊 Esporta CSV               Scarica la tabella come foglio di calcolo
  🖨️ Stampa Report             Report impaginato in orizzontale su A4

  Dopo ogni riavvio del browser l'app chiede di ricollegare il database:
  è normale, il browser non memorizza i permessi sui file tra una sessione e l'altra.


DOMANDE FREQUENTI
-----------------
  L'app si apre ma la tabella è vuota?
    -> Non hai collegato il database. Usa "🔗 Collega Archivio Condiviso"

  Mi dice "Il browser in uso non supporta il collegamento diretto al file"
    -> Stai usando Firefox o Safari. Apri con Chrome o Edge.

  Ho perso le modifiche?
    -> Controlla in basso a destra lo stato: "Salvato: <file> • <ora>"
       Se dice "Errore salvataggio condiviso", il file è aperto da un altro
       programma (o da un'altra persona) e non è scrivibile.

  Posso usarla su più computer?
    -> Sì, mettendo il JSON su un disco di rete. Un utente alla volta.
